M3Pipeline หมุน~15 นาที

โชว์: push แล้ว production เปลี่ยนเอง โดยไม่แตะ Vercel

M4ฐานข้อมูลต่อติด~45 นาที

โชว์: เข้าด้วย magic link สำเร็จ · ไม่ล็อกอินแล้วโดนเด้ง

M6CRUD ครุภัณฑ์Handoff · Cross-review~60 นาที

โชว์: เพิ่ม/แก้/ลบ + ข้อมูล 10 รายการ บน Preview URL — จบแล้วให้ OpenCode review

M7ยืม–คืนได้~40 นาที

โชว์: demo สด กดยืม → สถานะเปลี่ยน → กดคืน → กลับมา available

M8DashboardHandoff · เต็มรูปแบบ~30 นาที

โชว์: สร้างด้วย Cursor ทั้งฟีเจอร์ (รับช่วงจาก agy) + ตอบได้ว่ารู้ context จากไหน

ชั่วโมงสุดท้ายส่งมอบรวม ~50 นาที
M9ผ่านด่านคุณภาพ~30 นาที

โชว์: lint + tsc เขียว และ smoke test ผ่าน 1 เส้นทาง

M10Production v0.1.0~20 นาที

โชว์: เพื่อนใช้ระบบจากมือถือของเพื่อนเองได้ + มี tag v0.1.0
